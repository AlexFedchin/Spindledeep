Spindledeep · release of 26 November

Version 1.2.1

A build for Linuxand the portable one for Windows

A new release with everything since 1.2.0. This time there is a Linux build for the machine you now play on, next to the usual portable Windows build. The Windows installer could not be made here; see the last section.

The AppImage needs to be marked runnable once (chmod +x, or Properties → Permissions), then it starts with a double click. Saves and settings stay where they were (~/.config/Spindledeep), so a game in progress carries over.

What Is New Since 1.2.0

  • Stone: rougher engraved lines in the rock, wavering, swelling and breaking off differently in each kind of rock.
  • Films: the opening film and both ending films staged again, and a short film after one ending's titles.
  • The hands in the Hush can no longer reach you through rock.
  • Knots of light are gone, and E now ties, mends and sits.
  • Tips at the bottom of the screen are larger, brighter and marked by a red thread.
  • The thread holds steady at rock edges and no longer whips through thin slabs.
  • Hidden rooms open only when you touch their rock.
  • Bobbins roll on over you instead of stopping.

The Windows Installer

The installer (-setup.exe) was not built. To make its uninstaller, the build tool has to run a Windows program, which on Linux needs Wine, and Wine is not installed here. The portable .exe doesn't need it and is complete and carries version 1.2.1. To get the installer too, install Wine (sudo apt install wine) and I can build it here, or run build.cmd same on a Windows machine.
